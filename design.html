Ghid pentru materiale noi

Cum se adaugă o lecție nouă pe site și ce componente se pot folosi în ea.

Cum adaug un material nou

  1. Copiați fișierul materiale/_sablon.html și redenumiți copia, de exemplu materiale/cautare-binara.html. Folosiți litere mici, fără diacritice, cu cratimă între cuvinte.
  2. În fișierul nou schimbați trei lucruri: textul din <title>, atributul data-id="cautare-binara" de pe <body> (numele fișierului fără .html) și titlul din <h1>.
  3. Deschideți assets/catalog.js și adăugați un rând nou în lista MATERIALE. Ordinea din listă este ordinea lecțiilor în cadrul clasei.
  4. Scrieți conținutul lecției cu componentele de mai jos. Puteți copia orice bucată de aici.
  5. Gata. Lecția apare singură pe prima pagină, la clasa ei. Cuprinsul, bara de sus, eticheta cu clasa și legăturile spre lecția anterioară și următoare se fac automat.

Site-ul este format doar din fișiere, fără server. Funcționează deschis direct de pe calculator și poate fi pus pe orice găzduire de pagini statice (de exemplu GitHub Pages sau Netlify).

Componente

Pentru fiecare componentă: cum arată, apoi codul HTML de copiat.

Secțiune

Fiecare <section> cu id și <h2> apare în cuprins. Atributul data-toc dă o etichetă mai scurtă în cuprins.

HTML
<section id="teorie" data-toc="Ideea">
  <h2>Ideea tehnicii</h2>
  <p>Textul lecției.</p>
</section>

Bloc de cod

Codul se lipește așa cum este, fără nicio modificare, între cele două etichete. Primește automat culori și butonul de copiere.

HTML
<script type="text/x-cpp" class="cod">
#include <iostream>
using namespace std;

int main()
{
    cout << "Salut!";
    return 0;
}
</script>

Pseudocod

Cu lv (albastru, pointerul din stânga) și rv (portocaliu, pointerul din dreapta) se pot colora variabile.

st = 1; dr = n cât timp st < dr: ...
HTML
<div class="pseudo"><span class="lv">st</span> = 1;  <span class="rv">dr</span> = n
<span class="k">cât timp</span> <span class="lv">st</span> &lt; <span class="rv">dr</span>:
    ...</div>

Notă, formulă și complexitate

O notă scoate în evidență o idee sau o formulă. Complexitățile se pot marca verde (bună) sau roșu (prea lentă).

S[i] = max(a[i], S[i − 1] + a[i])

Atenție: suma poate depăși int.

Timp O(n), față de O(n²).

HTML
<div class="note r"><p class="big">S[i] = max(a[i], S[i − 1] + a[i])</p></div>
<div class="note"><p>Atenție: suma poate depăși <code>int</code>.</p></div>
<p>Timp <span class="cx">O(n)</span>, față de <span class="cx slow">O(n²)</span>.</p>

Simulare pas cu pas

Simulările se fac cu funcția Stepper din assets/site.js. În pagină se pune caseta, iar la finalul paginii, după site.js, un script care descrie pașii. Fiecare pas spune unde sunt pointerii (l, r), ce celule se colorează și ce text se afișează.

HTML
<div class="demo" id="demoDesign">
  <div class="stats" data-stats></div>
  <div class="cells" data-cells></div>
  <p class="status" data-status aria-live="polite"></p>
  <div class="ctrl">
    <button class="btn" type="button" data-prev>Înapoi</button>
    <button class="btn pri" type="button" data-next>Pasul următor</button>
    <button class="btn" type="button" data-play>Rulează</button>
    <span class="step-ct" data-ct></span>
  </div>
</div>
JS
Stepper(document.getElementById('demoDesign'), () => {
  const a = [3, 8, 1, 5], frames = [];
  let s = 0;
  for (let i = 0; i < a.length; i++) {
    s += a[i];
    frames.push({
      l: i, ln: 'i',                     // poziția pointerului și eticheta lui
      done: k => k < i,                  // celulele estompate
      stats: `<div><span>s =</span> <b>${s}</b></div>`,
      msg: `Adunăm a[${i}] = ${a[i]}, iar suma devine ${s}.`
    });
  }
  return { arr: a, frames };
});

Opțiuni pentru un pas: l și r (pozițiile pointerilor), ln și rn (etichetele lor), win: [st, dr] (interval colorat verde), good și bad (liste de poziții verzi sau roșii), done (o funcție care spune ce celule se estompează), base1: true (numerotare de la 1), stats și msg (textele afișate).
